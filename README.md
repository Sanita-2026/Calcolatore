# Calcolatore

`index.html` è un calcolatore di offerte in un unico file: aprilo direttamente nel browser, non serve installare nulla.

- Prezzo di listino, cursore di sconto (0–40%) e percentuale di commissione
- Prezzo scontato e commissione aggiornati in tempo reale
- Indicatore a colori: verde fino al 10%, ambra fino al 25%, rosso oltre
- Commissione persa per lo sconto rispetto al prezzo di listino
- Gli ultimi valori inseriti vengono ricordati nel browser
